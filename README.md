\# 🌾 CropYield Prediction Using XGBoost



\### An XGBoost-Based Predictive Framework for Crop Yield Estimation



\## 📌 About the Project



CropYield AI is a machine learning-based application designed to estimate agricultural crop yield using important agricultural and environmental parameters.



The system analyzes soil properties, rainfall, temperature, humidity, and historical yield data to generate crop yield predictions and provide useful agricultural insights.



The main objective is to help farmers and agricultural users make better-informed farming decisions using data-driven predictions.



\## 🎯 Objectives



\- Predict crop yield using the XGBoost algorithm.

\- Analyze important soil and climatic parameters.

\- Process and clean agricultural datasets.

\- Identify dataset columns automatically.

\- Compare different agricultural datasets.

\- Provide useful agricultural insights through visualizations.



\## ⚙️ Technologies Used



\- \*\*Frontend:\*\* React.js, TypeScript

\- \*\*Build Tool:\*\* Vite

\- \*\*Machine Learning:\*\* XGBoost-based prediction engine

\- \*\*Data Processing:\*\* PapaParse

\- \*\*Visualization:\*\* Recharts

\- \*\*AI Integration:\*\* Google Gemini API

\- \*\*Database Integration:\*\* Supabase (optional)



\## ✨ Key Features



1\. \*\*Crop Yield Prediction:\*\* Estimates crop yield using agricultural input parameters.

2\. \*\*Dataset Upload:\*\* Allows users to upload agricultural CSV datasets.

3\. \*\*Data Cleaning:\*\* Handles missing and inconsistent dataset values.

4\. \*\*Automatic Column Detection:\*\* Identifies relevant columns from uploaded datasets.

5\. \*\*Dataset Comparison:\*\* Compares multiple agricultural datasets.

6\. \*\*Feature Importance:\*\* Displays the contribution of important input parameters.

7\. \*\*Model Performance:\*\* Provides model evaluation and performance visualizations.

8\. \*\*Agricultural Insights:\*\* Generates useful information to support farming decisions.



\## 📊 Input Parameters



\- Crop Type

\- Soil Type

\- Soil pH

\- Nitrogen

\- Phosphorus

\- Potassium

\- Rainfall

\- Temperature

\- Humidity

\- Historical Yield



\## 🧠 Algorithm Used



\*\*XGBoost (Extreme Gradient Boosting)\*\*



XGBoost is a gradient boosting algorithm that builds decision trees sequentially to improve prediction accuracy.



It is used in this project to estimate crop yield based on agricultural and environmental data.



\## 🚀 Run Locally



\### Prerequisites

\- Node.js

\- npm

\- Git



\### Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/BabyVS-09/CropYield-Prediction-Using-XGBoost.git

&#x20;  ```



2\. Navigate to the project directory:



&#x20;  ```bash

&#x20;  cd CropYield-Prediction-Using-XGBoost

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  npm install

&#x20;  ```



4\. Configure environment variables using `.env.example` as a reference. Add your Gemini API key to `.env.local` if required.



5\. Start the application:



&#x20;  ```bash

&#x20;  npm run dev

&#x20;  ```



6\. Open the local URL displayed in your terminal.
